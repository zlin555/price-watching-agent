# Price Watcher Platform

用户自定义比价与提醒网站初始项目。

## 目录结构

- `frontend/`: 初始前端页面，目前是可直接打开的静态页面。
- `backend/`: 后端服务预留目录，用于后续实现用户登录、商品/链接追踪、定时爬取、价格提醒等能力。

## 当前功能雏形

- 用户输入商品链接、机票/酒店链接或股票代码。
- 配置目标价格、提醒方向和联系方式。
- 展示价格趋势、提醒状态和关注列表。
- 为后续登录、profile、定时任务、通知服务预留结构。
